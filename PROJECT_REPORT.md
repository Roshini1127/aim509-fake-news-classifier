# AIM-509 Project Work
## AI-Based Fake News Classification System

### 1. Abstract
This project explores machine-learning-based classification of news text.
The text is transformed into TF-IDF features and classified using
scikit-learn models.

### 2. Objectives
- Prepare and inspect a labeled news dataset.
- Convert text into numerical TF-IDF features.
- Train and compare multiple classification algorithms.
- Evaluate performance on a held-out test set.
- Provide a simple user interface for predictions.

### 3. Methodology
The dataset is split into training and testing subsets. TF-IDF is used
for text representation. Logistic Regression, Multinomial Naive Bayes,
and Linear Support Vector Classification are compared.

### 4. Selected model
Best model according to the notebook's F1 Score: Naive Bayes

### 5. Evaluation
See model_comparison.csv and evaluation_report.txt for the actual
results generated by this notebook. Do not claim results that were not
measured.

### 6. Tools and technologies
Python, pandas, scikit-learn, TF-IDF, joblib, and Streamlit.

### 7. Limitations and ethics
The classifier learns patterns from its training data and may make
incorrect predictions. Dataset bias, outdated information, satire,
and changes in writing style can affect results. Predictions should
not be treated as definitive fact-checking.

### 8. Future scope
Use a larger, well-documented dataset; validate on independent sources;
add source credibility checks; improve explainability; and monitor
performance across different topics and languages.

### 9. Conclusion
The project demonstrates a machine-learning workflow for text
classification, including training, evaluation, model saving, and a
basic web interface.
